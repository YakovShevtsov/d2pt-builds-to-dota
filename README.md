# D2PT → Dota 2 гайды

Переносит сборки героев с dota2protracker.com (7000+ MMR) в гайды Dota 2 на твоём аккаунте:
предметы с таймингами, порядок скиллов и таланты. Нужны Windows 10/11 и Steam с Dota 2,
запущенной на этом аккаунте хотя бы раз.

## Установка

Скачай `d2pt-builds-to-dota.exe` из [релизов](https://github.com/YakovShevtsov/d2pt-builds-to-dota/releases)
и запусти двойным кликом — откроется страница в браузере. Ставить ничего не нужно.

Мелочи при первом запуске:

- **«Windows protected your PC».** Файл не подписан сертификатом, поэтому SmartScreen ругается на любую
  новую программу. Нажми «Подробнее» → «Выполнить в любом случае».
- **Антивирус** тоже может насторожиться: внутри exe лежит движок Bun. Если файл заблокирован,
  добавь его в исключения или собери сам (см. ниже).
- **Положи exe в обычную папку** (Документы, Рабочий стол). Рядом с ним он создаёт папку `data`
  со списком установленных гайдов и кешем, поэтому в `Program Files` работать не будет.

## Как пользоваться

Страница работает только на этом ПК (`http://127.0.0.1:7353`), наружу ничего не открывается.

- Выбери аккаунт сверху.
- Кликай цифры ролей под героями: жёлтая — будет установлена, белая — установлена,
  зачёркнутая — будет удалена. Клик по картинке героя — выбрать его самые популярные роли.
  Бледные цифры — мало данных на D2PT.
- «Apply» — выполнить отмеченное. Тулза сама закроет Steam и Dota, запишет гайды и запустит всё обратно.
- «Update installed» — обновить все установленные гайды после патча.
- «Remove all» — отметить все установленные гайды на удаление.

Чтобы выйти — закрой чёрное окно.

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 22+. Запуск — `start.bat` (или `node server.js`).
Браузер не нужен: данные берутся встроенным в Windows `curl.exe`, а если Cloudflare его не пустит —
автоматически любым Chromium-браузером (Chrome, Edge, Яндекс, Opera, Brave, Vivaldi).

## Сборка exe

Нужен [Bun](https://bun.sh) (`winget install oven-sh.bun`). Собирается одной командой:

```
node build.js                 # dist/d2pt-builds-to-dota.exe для Windows
node build.js bun-linux-x64   # dist/d2pt-builds-to-dota для Linux (код под Linux ещё не адаптирован)
```

Страница, иконки и список предметов вшиваются внутрь файла. Свои данные (список установленных
гайдов и кеш) exe кладёт в папку `data` рядом с собой.

## Команды (для продвинутых)

```
node cli.js accounts                       # аккаунты Steam на этом ПК
node cli.js heroes shaman                  # поиск героя и его роли (в [скобках] — самые популярные)
node cli.js install lion:4,5 axe           # установить гайды (без ролей — берутся самые популярные)
node cli.js update                         # обновить все установленные гайды D2PT
node cli.js remove lion:4                  # удалить гайд (или --all — все гайды D2PT)
```

Флаги: `--account <ник>` (по умолчанию — последний вход), `--close-steam` (закрыть Steam автоматически),
`--dry-run` (собрать в папку `out/`, в Steam не писать), `--fresh` (не использовать кеш), `--fetch curl|browser`.

## Когда нужно закрывать Steam

- **Новые гайды и удаление** — только при закрытом Steam (гайд регистрируется в индексе Steam Cloud).
  Добавь `--close-steam`, и тулза закроет Steam сама. Перед правкой индекса делается резервная копия
  `remotecache.vdf.bak_d2pt_*`.
- **Обновление** существующих гайдов — Steam можно не закрывать, достаточно перезайти в Dota.

## Что тулза не трогает

Только гайды, которые создала сама (список — в `data/manifest.json`). Твои собственные гайды остаются как есть.

## Ограничения

- D2PT ограничивает частые запросы к одному герою. Ответы кешируются на 6 часов; если герой
  всё же получил «временно ограничил запросы» — повтори позже, прошлая версия гайда остаётся.
- Порядок скиллов — только первые 10 уровней (столько отдаёт D2PT), плюс таланты.

## Дисклеймер

Неофициальная тулза для личного использования. Не связана с dota2protracker.com, Valve или Steam.

- Данные о сборках — с dota2protracker.com, права на них принадлежат D2PT; список предметов — с OpenDota.
- Dota 2, изображения героев и предметов, иконки атрибутов и ролей, логотип Dota — собственность
  Valve Corporation. Логотип D2PT принадлежит dota2protracker.com.
- Тулза не трогает файлы игры — только текстовые гайды в папке облачных сохранений Steam.
